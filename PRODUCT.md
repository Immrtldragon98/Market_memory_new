# Market Memory — Product Contract

## Promise
Digital memory for market research and trading decisions.

## Core loop
Observe → Record → Decide → Remember → Review

## v1 pillars
1. Trading journal
2. Market observations
3. Watchlists
4. Price alerts
5. Market snapshots

## Non-goals for core v1
- automatic BUY / HOLD / SELL recommendations
- AI dependency for core workflows
- portfolio accounting
- thesis engine as primary navigation
- feature-heavy research terminal

AI, structured theses, and deeper company research may return later as optional extensions of the memory layer.
