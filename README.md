# Market Memory

**Digital memory for market research and trading decisions.**

Market Memory is a focused system for recording what you saw, what you thought, and what you decided around the market.

## Core product

1. **Trading journal** — record decisions, reasoning, confidence and mistakes.
2. **Market observations** — quickly save what you notice about an asset at a point in time.
3. **Watchlists** — keep the markets you care about close.
4. **Price alerts** — remember important levels without continuously watching the screen.
5. **Market snapshots** — freeze market context and your note so it can be revisited later.

## Core loop

**Observe → Record → Decide → Remember → Review**

## Architecture

- React Native / Expo
- TypeScript
- FastAPI
- Supabase

## Product principles

- Capture must be fast.
- Historical snapshots are immutable.
- User-owned data is isolated and authenticated.
- Focused workflows beat feature-heavy interfaces.
- AI may enrich memory later, but the core product must work without it.
